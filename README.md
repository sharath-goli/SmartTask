# SmartTask

SmartTask is a full-stack task planner with personal accounts, a live Eisenhower matrix, dashboard summaries, calendar, and a Pomodoro focus timer. The backend is Spring Boot 3.5 / Java 17; the frontend is React, TypeScript, and Vite. Task and focus data are stored in MySQL.

## Requirements

- Java 17 or newer, Maven 3.9+
- Node.js 20.19+ (or 22.12+) and npm
- MySQL 8.0+ (running locally)

## Run on Windows

1. Use your existing MySQL account if you already have one. For a new local account, choose a password and use the same value in `backend/.env`; these statements preserve an existing database and user:

   ```sql
   CREATE DATABASE IF NOT EXISTS smarttask CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   CREATE USER IF NOT EXISTS 'smarttask'@'localhost' IDENTIFIED BY 'choose-a-local-password';
   GRANT ALL PRIVILEGES ON smarttask.* TO 'smarttask'@'localhost';
   ```

2. Copy `backend/.env.example` to `backend/.env` and edit the database user and password to match the MySQL account you created. Replace the JWT secret with a random value of at least 32 bytes. `backend/.env` is ignored by Git and the run script reads it without printing its contents:

   ```powershell
   if (-not (Test-Path .\backend\.env)) { Copy-Item .\backend\.env.example .\backend\.env }
   notepad .\backend\.env
   ```

3. In one terminal, run the API from `backend`:

   ```powershell
   cd backend
   .\run.ps1
   ```

4. In another terminal, run the web app from `frontend`:

   ```powershell
   cd frontend
   if (-not (Test-Path .env.local)) { Copy-Item .env.example .env.local }
   npm install
   npm run dev -- --host 127.0.0.1
   ```

5. Open http://127.0.0.1:5173/ and register. The frontend is served by Vite; do not double-click `frontend/index.html` or open port 8080 as the website. Port 8080 is the API only. API docs are at http://localhost:8080/swagger-ui.html.

## Configuration

See `backend/.env.example` and `frontend/.env.example`. The backend uses `ddl-auto=update` for this small college project, so JPA creates/updates tables at startup. Back up data before changing entity schemas. Set `CORS_ORIGINS` to the exact production frontend origin when deploying. Never commit `.env` files or production secrets. Use HTTPS and a strong random JWT key in production.

## Features

- Registration/login with BCrypt password hashing and signed bearer JWTs. Every task and focus-session query is scoped to the authenticated account.
- Create, edit, delete, search, filter, sort, complete/reopen tasks, tags, estimates, due dates, recurring intervals, and parent/subtask relationships.
- Importance and urgency determine the four Eisenhower quadrants directly from task fields.
- Dashboard counts and completion history are calculated from persisted tasks. Empty accounts show useful onboarding states.
- Calendar by due date, daily planning list, focus timer with task association and persisted session duration, and due and overdue tasks surfaced on the dashboard and calendar; push/background reminders are not configured.
- Responsive layout, dark/light theme, and custom SVG-based productivity chart without a charting dependency.

## Architecture

`backend` is a layered Spring application (`controller`, `service`, `repository`, `entity`, `dto`, `security`, `config`). `frontend/src` contains API access, reusable components, and feature views. REST endpoints are rooted at `/api`; OpenAPI is generated by springdoc. MySQL is the sole persistence store.

## Checks

From `backend`: `mvn test` and `mvn package`.

From `frontend`: `npm test` and `npm run build`.

Integration with MySQL requires the local database and the environment above. On the development machine used for this build, the MySQL service was running, but it rejected the sample `smarttask` credentials and a passwordless `root` login. Registration, login, and persistence therefore were not verified end to end against this machine's database. Create the database user described above and set its credentials before starting the app. The current automated tests are unit tests and do not require MySQL.

## Deployment

Build the frontend with `npm run build` and the backend with `mvn package`. Serve `frontend/dist` from a static host and run `backend/target/smarttask-api-1.0.0.jar` on a Java 17 host with MySQL connectivity. Set database credentials, JWT secret, and allowed CORS origins as deployment environment variables. Do not expose the database publicly or use development credentials in production. This repository is initialized with Git; review `.gitignore` and make your own commits. No external service or deployment is configured.
